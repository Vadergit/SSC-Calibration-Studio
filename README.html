SSC Calibration Studio

Technical documentationMarkdown source ↗

Universal, open-source calibration software for Sensor Signal Conditioners (SSCs).

The goal is a single browser-based application for configuring, calibrating, programming and logging pressure-sensor SSCs from different manufacturers, supporting both original manufacturer calibration/evaluation boards and affordable Arduino-/ESP32-compatible microcontrollers as communication interfaces.

The existing Elmos E703.11 Calibration Web App is the starting point for the shared user interface and calibration workflow.

Studio v0.5.3#

Open Studio · Architecture and module integration · Changelog

Every manufacturer card opens its independent public calibration web app directly in a new browser tab. Device, adapter and task selection take place within that app. Elmos opens the standalone hardware calibrator; the pinned local v0.7.172 reference remains available under Related projects. The six other manufacturer apps provide simulation only; hardware drivers remain planned. See architecture.

Related projects#

  • Elmos E703.11 Calibration Web App: independent reference calibrator, pinned local integration in Studio.
  • SensorBridge Emulator: programmable Wheatstone bridge emulator for repeatable sensor signal tests. Web UI / demo. Currently a mathematical simulation; analogue hardware and accuracy not validated. Future Studio integration planned.

Planned workflow#

Studio: select manufacturer / SSC → open calibrator. Calibrator: select adapter, communication and task → connect / calibrate / verify / log.

The application will use interchangeable hardware adapters for original manufacturer boards and the open-source microcontroller firmware, plus device-specific drivers for register access, communication and calibration methods. Digital measurement readout is preferred where available; precision calibration may still require external reference measurements.

Full development roadmap and task checklist · Microcontroller firmware, native USB boards and communication protocols
