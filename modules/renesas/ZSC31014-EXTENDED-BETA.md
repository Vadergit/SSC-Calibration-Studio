# v0.7.14 extended native bridge calibration beta

Native Renesas/IDT communication board: pressure/temperature-compensated bridge calibration modes from 2 to 7 measurements, including separate TK0/TKE and parabolic bridge nonlinearity. Raw temperature output is temporarily prepared using unity coefficients, then the original temperature output trim is restored in the final EEPROM target. This is not an independent calibration of the temperature output. AFE changes invalidate captured points. Writes retain backup requirement, documented register masks, readback and power cycle. The fixed-point forward model was checked against 300 original DLL results, and the inverse solver was checked against synthetic measurement plans. Real sensor/adapter testing is still required; do not treat this beta as a production qualification. S-shaped curve is not enabled in the guided UI because silicon revision support must be confirmed. DIY ZSC31014 I2C adapters and other model-specific native algorithms are not covered by this change.
