# Unified connection workspace

Studio starts in the most recently selected native calibration workspace (Elmos by default). The common Connection dialog selects manufacturer, model and board; Elmos additionally selects the chip interface. Choices are stored locally. Cross-model navigation stays in the same tab, with an explicit warning for unfinished work and a block for active hardware connections. Native connection screens retain chip-specific settings and USB actions. A new page cannot reuse the original click for Web Serial, so the native Connect button still needs a separate click. No automatic connection on switching. The old overview is accessible with ?overview=1. Existing module-specific UI and algorithms remain native; this is shared navigation, not a full common rendering engine. Standalone Elmos untouched.
